## Projetos em destaque

### Sistema de Gerenciamento Escolar

Aplicação Full Stack desenvolvida com React, Node.js, Express e Sequelize, com integração a banco de dados MySQL.

- Autenticação de usuários.
- Gerenciamento de alunos e turmas.
- Cadastro e consulta de notas.
- Controle de permissões por perfil.

### PixelPlay

Projeto de desenvolvimento web com React e Vite, voltado para uma plataforma de jogos.

- Componentização com React.
- Organização de páginas e componentes.
- Navegação entre páginas.
- Funcionalidades de produtos e carrinho.

### Projetos de APIs REST

Desenvolvimento de APIs utilizando Node.js e Express, explorando rotas, middlewares, autenticação, validação de dados e integração com bancos de dados.
